# Quick Task 260531-0ea: Fix pre-existing api-integration.test.js failures

**Status:** Complete  
**Date:** 2026-05-30

## Task
Make `api-integration.test.js` gracefully skip when the Supabase remote DB is unavailable, instead of failing with 25 hard errors.

## Problem
The backend's `server.js` calls `process.exit(1)` when the Supabase PostgreSQL connection fails (timeout). The integration test spawns the backend, waits for it, and all 25 tests fail with `ECONNREFUSED` because the backend never starts.

## Solution
Added a `backendReady` flag and `itWhenReady()` wrapper that conditionally skips tests when the backend isn't available. All 25 tests now show as `skipped` instead of `failed` when the remote DB is unreachable.
