# Plan: Run All Tests and Report Results

## Objective

Run every test suite in the project — backend (Jest) and frontend (Vitest) — and produce a single consolidated report showing pass/fail counts, test file breakdown, and any failures with error details.

**Scope:**
- Backend: `cd backend && npm test` (Jest, 7 test files under `tests/`)
- Frontend: `cd frontend && npm test` (Vitest, 12 test files under `src/` and `tests/`)

## Output

A report file at `.planning/quick/260531-107-run-all-test-and-report-the-result/260531-107-TEST-REPORT.md`

---

## Task 1: Run Backend Tests

**Action:**
1. Run `cd backend && npm test -- --verbose` to execute all Jest tests
2. Capture stdout + stderr to a temp file
3. Parse the result:
   - Total test count, pass count, fail count
   - Per-file breakdown (file name, passed/total, pass/fail)
   - Any failure messages (error name, location, message)
   - Duration

**Verify:**
- Tests complete (success or failure — both are valid outcomes for reporting)
- Output captured to `$TEMP_DIR/backend-test-output.txt`

## Task 2: Run Frontend Tests

**Action:**
1. Run `cd frontend && npm test` to execute all Vitest tests
2. Capture stdout + stderr to a temp file
3. Parse the result:
   - Total test count, pass count, fail count
   - Per-file breakdown
   - Any failure messages
   - Duration

**Verify:**
- Tests complete (success or failure — both are valid outcomes for reporting)
- Outputs captured to `$TEMP_DIR/frontend-test-output.txt`

## Task 3: Produce Consolidated Test Report

**Action:**
1. Merge results from both test runs into a single report file at:
   `.planning/quick/260531-107-run-all-test-and-report-the-result/260531-107-TEST-REPORT.md`
2. Report structure:
   - **Summary table**: Suite | Total | Passed | Failed | Duration
   - **Per-file breakdown**: table for each suite with file name, result, test count
   - **Failures**: full error name, file:line, message for each failure (if any)
   - **Overall verdict**: ALL PASSED or N FAILURES found

**Verify:**
- Report file exists and is well-formatted Markdown
- Every test file from both suites is accounted for (no gaps)

- Pass/fail counts match actual test runner output (not assumed)
