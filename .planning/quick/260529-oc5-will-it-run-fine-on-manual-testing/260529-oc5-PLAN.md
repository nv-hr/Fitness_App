  <files>backend/.env</files>
  <action>
    1. Check if `backend/.env` exists and has `DATABASE_URL`, `JWT_SECRET`, `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET` populated (not placeholder values).
    2. Start the backend server in the background:
       - `cd backend && node src/server.js &`
       - Wait 5 seconds for startup
    3. Check if the server started successfully:
       - If it binds to port 3001 and shows "Server running on port 3001" and "Database connected" → server is healthy
       - If it exits with "Database connection failed" → database is unreachable (known IPv6 issue from Phase 13). Log the error.
    4. Regardless of database status, verify Express middleware loads:
       - Run `node -e "import('./src/app.js').then(() => console.log('App module loads OK')).catch(e => console.error('App module load FAILED:', e.message))"` from the backend directory
    5. Report database reachability and server start status clearly.
  </action>
  <verify>
    <automated>node -e "import('./src/app.js').then(() => console.log('PASS: App module loads')).catch(e => { console.error('FAIL:', e.message); process.exit(1) })"</automated>
  </verify>
  <done>
