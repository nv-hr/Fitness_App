## Tasks

- **Files:**

- **Action:** After `createActivityLog` succeeds, do a best-effort sync: find the weekly plan for the log date's week, find the day matching the log date, find the activity by ID, set `completed = true`, update `day.completed`, persist via `upsertPlan`, and update the server cache via `setCachedPlan`.
