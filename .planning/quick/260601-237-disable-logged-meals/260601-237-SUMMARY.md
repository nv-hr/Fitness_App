# Summary: Disable logged meal items in plan

## Result
When food is logged individually via the Log tab (or any POST `/api/food/log`), the corresponding item in the daily meal plan is now marked as `logged=true`. Once logged, the item shows a static ✓ badge instead of a clickable toggle button, and the Swap button is hidden — making it unchangeable.

## Changes
- `backend/src/controllers/food.controller.js` — After `createFoodLog`, syncs to meal plan via `markItemLogged` (error-tolerant)
- `frontend/src/features/food-log/components/MealCalendarSection.jsx` — Logged items show static ✓ badge; swap button hidden; only unlogged items show clickable toggle + swap

## Verification
- Backend unit tests: 6/7 suites pass (1 pre-existing failure)
- Logical: `foodId` must be present for plan sync (custom foods without foodId skip sync)
