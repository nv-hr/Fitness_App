    - `23505` (unique_violation) → `UNIQUE_VIOLATION`
    - `23503` (foreign_key_violation) → `FOREIGN_KEY_VIOLATION`
    - `23502` (not_null_violation) → `NOT_NULL_VIOLATION`
    - `23514` (check_violation) → `CHECK_VIOLATION`

    Default behavior: unknown error codes pass through with the original code and message.

    The function should accept a PostgreSQL Error object (with `.code`, `.message`, `.schema`, `.table`, `.constraint`, `.detail` properties) and return a normalized object that controllers can use for error handling. Return format left to agent discretion per CONTEXT.md, but should include:
    - `code`: Normalized error name (e.g., `UNIQUE_VIOLATION`)
    - `message`: Human-readable message
    - `sqlState`: Original PostgreSQL SQLSTATE code
    - `table`: Table name (pg provides this)
    - `constraint`: Constraint name (pg provides this)

    NOTE: The function should NOT throw or create AppError instances — it returns data that controllers use in their catch blocks. Controllers will replace `err.code === 'ER_DUP_ENTRY'` with `normalizeDbError(err).code === 'UNIQUE_VIOLATION'`.

    Exact code:
    ```javascript
    /**
     * Normalize PostgreSQL error codes to meaningful names.
     * Decouples controllers from database-specific error codes.
     *
     * @param {import('pg').DatabaseError} err - PostgreSQL error object
     * @returns {{ code: string, message: string, sqlState: string, table?: string, constraint?: string, detail?: string }}
     */
    export function normalizeDbError(err) {
      const CODE_MAP = {
        '23505': 'UNIQUE_VIOLATION',
        '23503': 'FOREIGN_KEY_VIOLATION',
        '23502': 'NOT_NULL_VIOLATION',
        '23514': 'CHECK_VIOLATION',
      };

      return {
        code: CODE_MAP[err.code] || err.code || 'UNKNOWN_DATABASE_ERROR',
        message: err.message || 'Database error occurred',
        sqlState: err.code || null,
        table: err.table || null,
        constraint: err.constraint || null,
        detail: err.detail || null,
      };
    }
    ```
