<objective>
**Rewrite profile.repository.js and user.repository.js to PostgreSQL syntax**

Convert all profile and user repository queries from MySQL syntax to PostgreSQL: replace `?` placeholders with `$1`, `LAST_INSERT_ID()` with `RETURNING *`, `ER_DUP_ENTRY` error codes with generic AppError handling, and fix boolean handling for pg's native BOOLEAN type.

**Purpose:** QRY-03 requires profile and user repositories to use PostgreSQL-compatible queries. Both repositories follow simpler patterns than food.repository.js (fewer functions, no JSON operations, no date arithmetic).

**Output:**
- `backend/src/repositories/profile.repository.js` — All queries converted to PostgreSQL syntax
- `backend/src/repositories/user.repository.js` — All queries converted to PostgreSQL syntax
</objective>
