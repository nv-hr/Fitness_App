<behavior>
  - **DAY_STATUS enum** exports { INCOMPLETE, COMPLETED, PAST_INCOMPLETE } as string constants
  - **getWeekStartsForMonth(date)** returns an array of Date objects — each a Monday weekStart for every week overlapping the given month. Must handle:
    - First week start = the Monday on or before the 1st of the month
    - Last week end = the Sunday on or after the last day of the month
    - Returns 5-6 weekStarts for a standard month
    - Edge case: June 2026 (Mon May 25 start → Sun Jul 5 end) — 6 week starts
  - **buildMonthGrid(date)** returns a flat array of all day Date objects in the visible grid (from gridStart Monday to gridEnd Sunday), using eachDayOfInterval. Used to iterate and compute day status.
  - **computeDayStatus(dateStr, planDay, isPast)** returns DAY_STATUS enum:
    - If planDay exists and is completed/green → DAY_STATUS.COMPLETED
    - If isPast and (no planDay OR planDay not completed) → DAY_STATUS.PAST_INCOMPLETE
    - Otherwise (future or today with no completion) → DAY_STATUS.INCOMPLETE
    - Edge: today without plan → INCOMPLETE (not PAST_INCOMPLETE)
    - `dateStr` format: 'YYYY-MM-DD'
</behavior>

<action>
Create CalendarGrid as a pure presentational component wrapping react-day-picker v9 DayPicker:

```jsx
import { DayPicker } from 'react-day-picker';
import { isBefore, startOfDay, startOfToday } from 'date-fns';
import { DAY_STATUS } from './calendarUtils.js';

export default function CalendarGrid({ currentMonth, onMonthChange, selectedDay, onDaySelect, dayStatusMap }) {
  // dayStatusMap: Map<string, DAY_STATUS enum> keyed by 'YYYY-MM-DD'
  
  const today = new Date();
  
  // Define modifiers based on dayStatusMap
  const modifiers = {
    incomplete: (day) => dayStatusMap.get(format(day, 'yyyy-MM-dd')) === DAY_STATUS.INCOMPLETE,
    completed: (day) => dayStatusMap.get(format(day, 'yyyy-MM-dd')) === DAY_STATUS.COMPLETED,
    pastIncomplete: (day) => dayStatusMap.get(format(day, 'yyyy-MM-dd')) === DAY_STATUS.PAST_INCOMPLETE,
    today: (day) => isSameDay(day, today),
    // Days outside month are automatically handled by DayPicker (disabled/outside modifiers)
  };

  // Define modifier styles for color coding (per UI-SPEC color system)
  const modifierStyles = {
    incomplete: { backgroundColor: '#dbeafe', color: '#1e40af', borderRadius: '4px' },
    completed: { backgroundColor: '#dcfce7', color: '#166534', borderRadius: '4px' },
    pastIncomplete: { backgroundColor: '#f3f4f6', color: '#9ca3af', borderRadius: '4px' },
    today: { outline: '2px solid #2563eb', outlineOffset: '2px', borderRadius: '4px' },
  };

  // When selected modifier is active, combine selection style with status
  // Use `modifiers.selected` disabled — DayPicker handles selection styling internally

  return (
    <DayPicker
      mode="single"
      selected={selectedDay}
      onSelect={onDaySelect}
      month={currentMonth}
      onMonthChange={onMonthChange}
      modifiers={modifiers}
      modifierStyles={modifierStyles}
      weekStartsOn={1} // Monday
      showOutsideDays={true}
      // Hide default nav caption — MonthNav handles it externally
      // Per react-day-picker v9, set `captionLayout="dropdown"` or hide nav components
      // Use components prop to render empty Nav if needed, or rely on captionLayout="label"
      // (exact API depends on v9 version — verify with Context7 `/dbradley/react-day-picker`)
    />
  );
}
```

Key implementation details:
1. **Import `format` from date-fns** for the dayStatusMap key lookup inside modifier functions
2. **Modifier functions** must handle undefined map entries gracefully (return false)
3. **Selected day style**: DayPicker internally applies `rdp-day_selected` class. For styling, provide `styles` prop: `{ day_selected: { outline: '2px solid #1e40af', outlineOffset: '-2px', borderRadius: '4px' } }` to combine with modifier styles. Per UI-SPEC priority: Selected > Today > Status color.
4. **Hide default navigation**: react-day-picker v9 shows built-in nav by default. Since MonthNav handles navigation externally, hide the default nav by using `components={{ Nav: () => null }}` or check v9 docs for `showNavigation={false}`.
5. **Outside days**: `showOutsideDays={true}` shows days from adjacent months. Use `modifiers` with `outside` to dim them: add `outside: { opacity: 0.4 }` to modifierStyles.
6. **Responsive**: DayPicker handles responsive cell sizing automatically per UI-SPEC.

Use Context7 (`context7_query-docs`) if needed to verify exact react-day-picker v9 API for:
- Hiding built-in navigation buttons (MonthNav handles it externally)
- Custom styling via `styles` vs `modifierStyles` for selected state
- Caption layout configuration

See the [UI-SPEC color system](@.planning/phases/34-calendar-shared-components/34-UI-SPEC.md) for exact color values.

Per D-15 — CalendarGrid receives precomputed status enums and stays pure/reusable.
Per D-03 — inline styles only.
