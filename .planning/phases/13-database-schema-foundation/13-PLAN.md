## Tasks

### Task 1: Add intensity_level ENUM, activity_logs, and weekly_plans tables

**File:** `backend/db/schema.sql`

Add `intensity_level` ENUM before the existing `DO $$` block, and new tables after `user_activity_log`.

**ENUM definition:**
```sql
DO $$ BEGIN
    IF NOT EXISTS (SELECT 1 FROM pg_type WHERE typname = 'intensity_level') THEN
        CREATE TYPE intensity_level AS ENUM ('light', 'moderate', 'vigorous');
    END IF;
END $$;
```

**activity_logs table:**
```sql
CREATE TABLE IF NOT EXISTS activity_logs (
    id INT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    user_id INT NOT NULL,
    activity_id INT NOT NULL,
    duration_min INT NOT NULL,
    intensity intensity_level NOT NULL,
    calories_burned INT NOT NULL,
    logged_date DATE NOT NULL,
    created_at TIMESTAMPTZ DEFAULT NOW(),
    FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE,
    FOREIGN KEY (activity_id) REFERENCES activities(id) ON DELETE CASCADE
);
```

**weekly_plans table:**
```sql
CREATE TABLE IF NOT EXISTS weekly_plans (
    id INT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    user_id INT NOT NULL,
    week_start DATE NOT NULL,
    plan_data JSONB NOT NULL DEFAULT '{}'::jsonb,
    status TEXT NOT NULL DEFAULT 'active',
    created_at TIMESTAMPTZ DEFAULT NOW(),
    updated_at TIMESTAMPTZ DEFAULT NOW(),
    FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE,
    UNIQUE(user_id, week_start)
);
```

Add indexes after existing indexes:
```sql
CREATE INDEX IF NOT EXISTS idx_activity_logs_user_date ON activity_logs(user_id, logged_date);
CREATE INDEX IF NOT EXISTS idx_weekly_plans_user_week ON weekly_plans(user_id, week_start);
```

**Verification:** Read schema.sql and confirm all new ENUM, tables, and indexes appear with correct columns/FKs.

**Commit message:** `feat(db): add intensity_level ENUM, activity_logs, and weekly_plans tables`
