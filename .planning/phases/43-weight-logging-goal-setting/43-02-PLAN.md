<interfaces>
**Backend API contract (built in Plan 01):**

```
POST /api/progress/weight
  Body: { weightKg: number, loggedDate: string (YYYY-MM-DD), notes?: string }
  Response: { success: true, data: { id, user_id, weight_kg, logged_date, source, notes, created_at } }
  Errors: 400 (validation), 401 (unauth)

GET /api/progress/weight?limit=N
  Response: { success: true, data: [ { id, user_id, weight_kg, logged_date, source, notes, created_at }, ... ] }
  Sorted by logged_date DESC
  source: "auto" or "manual"

DELETE /api/progress/weight/:id
  Response: { success: true, data: { deleted: true } }
  404 if not found / not owned

GET /api/profile
  Response includes: { profile: { ..., target_weight_kg, target_date }, ... }

PUT /api/profile
  Body includes: { ..., targetWeightKg, targetDate }
  Response includes: { profile: { ..., target_weight_kg, target_date }, ... }
```

**Existing HTTP helper pattern (shared/lib/http.js):**
```javascript
export async function apiGet(path) { return apiFetch(path, { method: 'GET' }); }
export async function apiPost(path, body) { return apiFetch(path, { method: 'POST', body: JSON.stringify(body) }); }
export async function apiDelete(path) { return apiFetch(path, { method: 'DELETE' }); }
```
