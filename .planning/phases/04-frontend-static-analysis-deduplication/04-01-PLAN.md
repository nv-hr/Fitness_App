  <action>
    Install fallow globally if not available: `npm install -g fallow` (or verify with `npx fallow --version`).

    Run both analyses from the project root (so the Vite plugin auto-detects the frontend workspace):

    ```
    npx fallow dead-code --format json --quiet 2>/dev/null > .planning/phases/04-frontend-static-analysis-deduplication/04-01-fallow-dead-code.json || true
    npx fallow dupes --format json --quiet --mode mild 2>/dev/null > .planning/phases/04-frontend-static-analysis-deduplication/04-01-fallow-dupes.json || true
    ```

    IMPORTANT (per fallow SKILL.md Agent Rules): Always append `|| true` because exit code 1 means "issues found" (not a runtime error). Use `--format json --quiet 2>/dev/null` for clean machine-readable output.

    After running, read the JSON output to extract:
    - `unused_files[]` — files with no consumers
    - `unused_exports[]` — exports never imported elsewhere
    - `unused_dependencies[]` — packages in package.json never imported

    NOTE on lucide-react: `lucide-react` is declared in the ROOT `package.json` (monorepo workspace), not `frontend/package.json`. If fallow flags it as unlisted/unused at the workspace level, this is a false positive — document it as such in the SUMMARY but do NOT flag it for removal.
  </action>

    </automated>
  </verify>
  <done>Both JSON files exist and contain valid fallow output (check `total_issues` field in dead-code JSON and top-level `kind` field is "dead-code").</done>
