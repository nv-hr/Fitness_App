# Requirements Archive: v1.3 Activity Tracking & Smart Suggestions

**Archived:** 2026-05-31
**Status:** ✅ SHIPPED

## v1 Requirements

Requirements for v1.3 Activity Tracking & Smart Suggestions. All were implemented. Traceability table was not updated during development — actual status confirmed by implementation.

### Activity Logger

- [x] **ACT-01**: User can log an activity by selecting from the existing activity database, entering duration in minutes, and choosing intensity level (light/moderate/vigorous) — **Validated** (Phase 14)
- [x] **ACT-02**: User can view their activity history list showing date, activity name, duration, intensity, and calories burned — **Validated** (Phase 14)
- [x] **ACT-03**: User can delete logged activities from history — **Validated** (Phase 14)
- [x] **ACT-04**: Daily activity summary shows total active minutes and calories burned, with net calorie display (consumed − burned vs TDEE target) — **Validated** (Phase 14)

### LLM Weekly Activity Suggestions

- [x] **LLM-01**: System auto-generates a personalized weekly activity plan by selecting from the existing activity database, considering user's profile (weight, goals, activity level) and recent activity history — **Validated** (Phase 15)
- [x] **LLM-02**: User can view their weekly activity plan as day-by-day cards showing suggested activities — **Validated** (Phase 16)
- [x] **LLM-03**: User can request to regenerate a single day/card from the weekly plan (rate-limited to prevent abuse) — **Validated** (Phase 16)
- [x] **LLM-04**: System gracefully falls back to cached plan or shows a message when LLM is unavailable — **Validated** (Phase 15 — fallback plan generation displays cached plan)
- [x] **LLM-05**: LLM provider integration with OpenRouter API key management, rate limiting for cost control, and output validation to ensure only database activities are suggested — **Validated** (Phase 15 — OpenRouter SDK, 5 req/15min rate limiter, Levenshtein fuzzy matching validation)

### v2 Requirements (Deferred)

- **ACT-05**: User can add custom activities with name and calories per minute — deferred to future release
- **ACT-06**: User can one-click log a suggested activity from the weekly plan — deferred to future release
- **ACT-07**: User can edit previously logged activities — deferred to future release (delete-and-recreate sufficient)
- **NOTF-01**: User receives weekly plan reminder at start of week — deferred
- **NOTF-02**: User receives daily activity reminder — deferred

### Out of Scope (Re-verified)

| Feature | Reason | Still Valid? |
|---------|--------|-------------|
| Custom activity entry | Not selected for this milestone | ✅ Yes |
| One-click plan-to-log | Deferred to v2; requires deeper UX work | ✅ Yes |
| Edit logged activities | Delete-and-recreate is sufficient for v1.3 | ✅ Yes |
| Notifications (email/push) | Out of scope for activity tracking milestone | ✅ Yes |
| Real-time activity sync | No wearable/device integration | ✅ Yes |
| Social features | Not core to individual health tracking | ✅ Yes |
| LLM-generated activity descriptions | LLM only selects from database | ✅ Yes |
