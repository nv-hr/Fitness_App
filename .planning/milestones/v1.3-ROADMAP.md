# Milestone v1.3: Activity Tracking & Smart Suggestions

**Status:** ✅ SHIPPED 2026-05-31

## Overview

Add activity logging and LLM-powered weekly activity planning to enhance the exercise recommendation system. Delivers full CRUD activity logging with server-authoritative calorie calculation and AI-generated 7-day personalized workout plans via OpenRouter.

## Milestone Summary

**Key Decisions:**

- Intensity multipliers server-authoritative: light=0.7, moderate=1.0, vigorous=1.3
- GET endpoint returns cached plan with fromCache flag, avoiding DB hit and rate-limit quota
- Both POST /generate and POST /regenerate-day share weeklyPlanLimiter (5 req/15min per user)
- regenerateDay generates full plan but merges only one day, preserving other days
- Per-day retryAfter tracked in dayRetryAfters object for independent per-card rate limits
- getMonday helper computes ISO week start; week start normalized server-side
- Activity Logger independent and shipped before LLM feature (Phase 14 → Phase 15)
- LLM uses triple fallback chain: primary → fallback → openrouter/free
- node-cache with 1-hour TTL, maxKeys: 1000 for memory safety

**Issues Resolved:**

- Integration test failures fixed (checkDbConnection, describeIf graceful skip)
- Session pooler retested — all 81 tests pass
- OpenRouter model IDs updated with `:free` suffix
- LLM primary model returns empty responses — fallback handles generation with correction prompts
- Frontend test framework dependency conflict resolved
