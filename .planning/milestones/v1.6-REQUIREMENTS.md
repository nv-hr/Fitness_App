# Requirements: v1.6 Activity Planner Rework

**Archived:** 2026-05-31
**Status:** ✅ SHIPPED

## v1.6 Requirements

### Variable-Day Scheduling

- [x] **SCHD-01**: User can select 4-6 available days per week when generating a plan — **Implemented** (Phase 32)
- [x] **SCHD-02**: System generates plans with variable activity days based on user's available days selection — **Implemented** (Phase 30)
- [x] **SCHD-03**: Rest days are displayed as rest day cards in the weekly plan view — **Implemented** (Phase 32)

### Profile-Driven Selection

- [x] **PROF-01**: LLM selects activity types based on user's fitness goal (lose weight, maintain, build muscle) — **Implemented** (Phase 30)
- [x] **PROF-02**: LLM adjusts activity duration and intensity based on user's activity level — **Implemented** (Phase 30)
- [x] **PROF-03**: LLM can assign multiple activities per day based on user profile — **Implemented** (Phase 30)

### Activity Swapping

- [x] **SWAP-01**: User can click a swap button on any activity in the plan — **Implemented** (Phase 32)
- [x] **SWAP-02**: LLM picks a replacement activity when user swaps — **Implemented** (Phase 31)
- [x] **SWAP-03**: Swapped activity replaces in-place in the cached plan without full regeneration — **Implemented** (Phase 31)
- [x] **SWAP-04**: Swap has a dedicated rate limit separate from generate/regenerate — **Implemented** (Phase 31)

### Plan Migration

- [x] **MIGR-01**: Old-format plans are lazily regenerated on next visit — **Implemented** (Phase 33)
- [x] **MIGR-02**: Plan data includes format_version to distinguish old vs new format — **Implemented** (Phase 30)
