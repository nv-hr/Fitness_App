Create the WeightTrendChart component at `frontend/src/features/progress/components/WeightTrendChart.jsx`.

**Props:** `{ profile, refreshKey }` — both optional. `profile` carries `target_weight_kg` for the goal line. `refreshKey` triggers data re-fetch when changed (matches pattern from WeightHistoryTable).

**State:**
- `entries` (array): weight entries from API
- `loading` (boolean): true during fetch
- `error` (string): error message if fetch fails
- `activeRange` (number): 30, 60, or 90 (default 30)

**Data fetching:**
- On mount and when `refreshKey` changes, call `getWeightHistory(90)` (fetch max range, filter client-side)
- Pattern: same as WeightHistoryTable — `useEffect` with async/await, try/catch, loading/error states

**Date range filtering:**
- Use `date-fns` `subDays` and `parseISO`/`format` to compute cutoff date
- Filter entries where `parseISO(entry.logged_date) >= cutoffDate`
- Sort filtered entries by `logged_date` ascending (Recharts plots left-to-right)

**Render logic (CHRT-04):**

1. **Loading** (`loading && entries.length === 0`):
   - Renders container shell with "Loading chart..." centered text
   
2. **Error** (`error && entries.length === 0`):
   - Renders container shell with error text in red

3. **Empty** (`!loading && filteredEntries.length === 0 && totalEntries === 0`):
   - Renders: "No weight data yet. Log your first weight to see your trend."

4. **Insufficient data** (`filteredEntries.length === 1`):
   - Renders: "At least 2 weight entries are needed to show a trend. Log more weights."

5. **Normal** (`filteredEntries.length >= 2`):
   - Renders full chart (see below)

**Date range button group (above chart, always visible when data exists):**
- Three buttons: "30 days", "60 days", "90 days"
- Active button: dark background (`#2563eb`), white text
- Inactive buttons: light background (`#f3f4f6`), dark text
- Clicking sets `activeRange` and re-filters data (no new fetch)

**Chart config (CHRT-01, CHRT-02, CHRT-03):**
```jsx
import { LineChart, Line, XAxis, YAxis, CartesianGrid, Tooltip, ReferenceLine, ResponsiveContainer } from 'recharts';

<ResponsiveContainer width="100%" height={300}>
  <LineChart data={filteredEntries} margin={{ top: 5, right: 20, left: 10, bottom: 5 }}>
    <CartesianGrid strokeDasharray="3 3" stroke="#e5e7eb" />
    <XAxis
      dataKey="logged_date"
      tickFormatter={(val) => format(parseISO(val), 'MMM d')}
      stroke="#9ca3af"
      fontSize={12}
    />
    <YAxis
      domain={autoScaleDomain}  // computed: [minWeight - 2, maxWeight + 2]
      tickFormatter={(val) => `${val} kg`}
      stroke="#9ca3af"
      fontSize={12}
      width={70}
    />
    <Tooltip
      labelFormatter={(val) => format(parseISO(val), 'MMM d, yyyy')}
      formatter={(val) => [`${parseFloat(val).toFixed(1)} kg`, 'Weight']}
    />
    <Line
      type="monotone"
      dataKey="weight_kg"
      stroke="#2563eb"
      strokeWidth={2}
      dot={{ r: 4, fill: '#2563eb' }}
      activeDot={{ r: 6 }}
      connectNulls={false}
    />
    {/* CHRT-03: Goal reference line */}
    {profile?.target_weight_kg && (
      <ReferenceLine
        y={profile.target_weight_kg}
        stroke="#dc2626"
        strokeDasharray="5 5"
        strokeWidth={2}
        label={{
          value: `Goal: ${profile.target_weight_kg} kg`,
          position: 'right',
          fill: '#dc2626',
          fontSize: 12,
        }}
      />
    )}
  </LineChart>
</ResponsiveContainer>
```

**Y-axis domain calculation (CHRT-02):**
- Extract min and max `weight_kg` from filtered entries
- `dataMin = Math.min(...weights)`, `dataMax = Math.max(...weights)`
- Return: `[Math.max(0, dataMin - 2), dataMax + 2]` — clamp lower to 0 to prevent negative axis

**Styling:**
- Container: `border: '1px solid #e5e7eb', borderRadius: '8px', padding: '1rem', background: '#fafafa'` (matches WeightHistoryTable)
- Title: "Weight Trend" heading above chart
- Empty/insufficient states: italic grey centered text
- Follow inline styles pattern from existing components (no CSS framework per project conventions)

**Edge cases:**
- If `profile.target_weight_kg` is null/undefined → no ReferenceLine rendered (falsy check)
- If all data filtered out by date range but total entries > 0 → show "No data in selected range" message with button to switch range
- If `profile` not provided → chart renders without goal line (no crash)
- `refreshKey` prop changes → re-fetch and re-render
