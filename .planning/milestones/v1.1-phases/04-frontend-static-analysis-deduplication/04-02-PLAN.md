    Create `frontend/src/shared/ui/MetricItem.jsx` — a semantic component for displaying a single fitness metric:

    Props interface:
    - `icon` (ReactElement) — the lucide-react icon element, pre-sized by the caller (e.g., `<Flame className="w-3.5 h-3.5 text-orange-500" />`)
    - `label` (string) — ALL-CAPS label text (e.g., "Calories Burned")
    - `value` (number | string) — the primary numeric value
    - `unit` (string) — the unit suffix (e.g., "kcal", "mins", "%")
    - `className` (string, optional) — additional classes for the wrapper `<div>`

    The component must render with EXACTLY the following className structure (match what ActivitySummary and CalorieSummary currently render to avoid visual regression):
    - Wrapper: `<div className={`space-y-1 ${className}`}>`
    - Label `<p>`: `text-[10px] sm:text-xs font-semibold text-slate-400 uppercase tracking-wider flex items-center gap-1`
    - Value `<p>`: `text-xl sm:text-2xl font-display font-black text-white`
    - Unit `<span>`: `text-xs sm:text-sm font-sans font-medium text-slate-500`

    Include JSDoc explaining WHY this component exists (eliminates 7+ duplicate metric cell implementations across summary panels).

    ---

    Create `frontend/src/shared/ui/Card.jsx` — a primitive layout container:

    Props interface:
    - `className` (string, optional) — additional/override classes merged after the base classes
    - `children` (ReactNode) — slot content

    Must render: `<div className={`p-6 rounded-2xl border transition-all duration-300 ${className}`}>{children}</div>`

    Include JSDoc explaining WHY this wrapper exists (standardizes the card container used in all summary panels and prevents className drift across features).

    ---

    Update `frontend/src/shared/ui/index.js` — add both new exports at the end of the existing barrel:
    ```
    export { default as MetricItem } from './MetricItem.jsx';
    export { default as Card }       from './Card.jsx';
    ```

    CRITICAL (per fallow SKILL.md pitfall): Do NOT import from `shared/ui/index.js` inside MetricItem.jsx or Card.jsx — this creates a re-export cycle. MetricItem and Card must only import from React or lucide-react (external packages).

    CRITICAL (TailwindCSS JIT safety per RESEARCH.md pitfall 4): Accept icon elements as ReactElement props (caller controls icon className), not string color names. This prevents partial class name templating that TailwindCSS JIT cannot statically detect.
