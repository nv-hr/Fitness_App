# Tech Stack

## Frontend
- React 19, Vite 8, React Router 7
- UI/State: TanStack React Query, React Hook Form, Zod
- Styling: TailwindCSS v4, Lucide React, Recharts, React Day Picker
- Package Manager: npm

## Backend
- Express 5 (ESM), Node.js >=18
- Auth: Passport (JWT + Google OAuth)
- Security: Helmet, express-rate-limit
- Database: Supabase PostgreSQL 17 (pg driver, no ORM)
- External API: OpenRouter (for LLM features)

## Tooling
- Jest for testing
- Vite for dev and build
- Docker (multi-stage build)
- TypeScript/TSX for compilation and linting
