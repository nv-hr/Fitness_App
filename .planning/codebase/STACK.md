# Technology Stack

## Frontend
- **Framework**: React 19.0
- **Build Tool**: Vite 6.2
- **Styling**: TailwindCSS 4.1
- **Icons**: lucide-react
- **Animations**: motion
- **Language**: TypeScript (using tsx)

## Backend
- **Runtime**: Node.js
- **Framework**: Express 4.21
- **AI SDK**: @google/genai
- **Language**: TypeScript

## Monorepo Tooling
- **Workspaces**: npm workspaces (frontend, backend)
- **Task Runner**: concurrently (for running dev servers)
- **Environment**: cross-env, dotenv
