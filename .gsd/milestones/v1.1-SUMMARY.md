## Lessons Learned
- Creating custom React hooks (e.g. `useProfileForm`, `useFoodLog`) is highly effective for separating UI display from business logic and state management.
- Theme variable customization in Tailwind CSS should be adjusted carefully to preserve contrast and readability in dark themes (avoid assigning dark gray values to default light gray variables).
