## Data Flow

1. User interacts with Frontend (React UI).
2. Frontend makes HTTP requests via `shared/lib/http.js` to Backend APIs.
3. Backend API (`backend/src/routes`) routes requests to Controllers.
4. Controllers call Services (e.g. `mealPlan.service.js`) for business logic.
5. Services interact with Repositories which run queries against PostgreSQL.
6. Some services integrate with external APIs (OpenAI) for LLM generation.
